What’s new in Sameko 1.4.0

Vietnamese and Chinese interface, Vim Mode, new themes and safer saving.

Interface languages

English, Tiếng Việt and 简体中文 in Settings › Appearance › Language. Code and program output are never translated.

Vim Mode

Turn it on in Settings › Editor; :w, :q and :wq work, with its own shortcut profile.

Stderr card

cerr output gets its own card under Input / Output / Expected; AC/WA is judged on stdout only.

New themes

Catppuccin Mocha, Gruvbox Dark, Crimson, Event Horizon, and new Kawaii Dark and Kawaii Light with video backgrounds.

Safer saving

No half-written files after a crash or full disk, and a failed save stops Build, Run and F5.

Faster start

Later launches start faster, clangd starts with the first C++ tab, and typing in large files is lighter.

Sameko Dev C++ Wiki

Documentation from basics to advanced features.

Sameko Dev C++ is a free, open-source (MIT) C++ IDE for competitive programming and education, built on the Monaco editor. On Windows it bundles GCC 16.1.0, clangd and GDB, so you can write, run and debug C++ right after installing, without setting up MinGW yourself. This guide covers version 1.4.0.

Who is Sameko for?

  • Beginners who need a simple environment without the complexity of Visual Studio
  • Competitive programmers who need fast builds, test cases and Competitive Companion
  • Students who need a portable IDE to use on school computers via USB

Installing Sameko IDE

Which one should I choose?

Windows has 2 downloads:

  • Installer (sameko-dev-cpp-setup-<version>.exe) - Start Menu and desktop shortcuts, "Open with" for C++ files, auto-updates and an uninstaller. Recommended for most users.
  • Portable (.zip) - Extract and run anywhere. No admin rights or registry changes. Great for USB drives or school computers. Auto-update is not available in portable mode.

Download Sameko

Go to the homepage and click Download, or get the files from GitHub Releases.

Install or Extract

Installer: run the .exe and follow the steps. It asks for administrator rights only if you install into Program Files.
Portable: extract to a folder such as D:\Sameko-IDE\.

Run Sameko Dev C++

Start it from the Start Menu, or double-click Sameko Dev C++.exe in the portable folder.

Windows Defender warning

A new app can show "not commonly downloaded" or SmartScreen. Choose Keep, or More info → Run anyway.

Linux packages

Linux releases are available as AppImage, .deb and .tar.gz. They do not bundle a compiler; install g++, gdb, clangd and astyle from your distribution so Sameko can detect them.

Creating your first project

After opening the IDE, write and run a Hello World program to check that everything works.

#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << "Hello, Sameko!" << '\n';
    return 0;
}

Steps:

  1. Press Ctrl + N for a new file (it starts from your template in Settings › Template) and paste the code
  2. Press Ctrl + S to save it as hello.cpp
  3. Press F11 to build and run
  4. The output appears in the Terminal and in the Output card; the status bar shows run time and peak memory
Tip

F9 compiles only, F10 runs without building, F11 does both. The same choices are in the caret next to the Run button.

Compiler Settings

Sameko uses GCC 16.1.0 on Windows. Change the standard, optimization and extra flags in Settings › Compiler.

C++ Standard

Pick any standard from C++98 to C++26. Default is C++17, the standard most online judges and contestants use.

Standard Description
C++98 Legacy, rarely used today
C++11 / C++14 Stable, widely used, supports auto, lambdas
C++17 (Default) The usual choice for competitive programming
C++20 Adds Ranges, Concepts, Modules
C++23 Adds std::print, std::expected
C++26 Available with GCC 16.1.0; use when your target compiler supports the feature

Common Compiler Flags

  • -O2 - Optimize for speed, as most online judges do
  • -Wall - Show warnings, helps find bugs
  • -g - Add debug information (F5 adds it for you)
Fast rebuilds

Builds use a precompiled bits/stdc++.h, and building an unchanged file reuses the last executable.

Theme Customizer

The live preview is a small copy of the real window: click any part of it to jump to its color. Colors take HEX, RGB or RGBA, each changed color has its own undo button, and Ctrl + Z / Ctrl + Y undo and redo. Edits stay in the preview until you save.

You can add a background image or video with an opacity slider, edit the theme as JSON, and export it. Exported themes include their background files.

Interface scale and background video

Settings › Appearance has Interface Scale (80–200%, Auto enlarges it on 4K screens) and an Animated Background switch to turn a theme's video off. The video pauses on its own while you work in another window.

Editor

Sameko uses the Monaco Editor, the same engine that powers VS Code, with clangd for C++ language features.

Key Editor Features

  • IntelliSense - clangd-backed completion, hover and signature help for the STL and your own code
  • Live Code Checking - errors and warnings while you type, from clangd (about 100–130 ms)
  • Format Code - Ctrl + Shift + A, with 13 AStyle styles in Settings › Editor › Format Style, and Format on Save for C/C++ files
  • Auto-close for types - typing { after struct Name (or class, union, enum) closes it as {};
  • Multi-cursor - hold Alt and click, or Ctrl + D to select the next match
  • Find & Replace - Ctrl + H with regex support
  • Split Editor - Ctrl + \ to work on two files side by side
  • Bracket colorization, minimap and code folding

Markdown and test files

A .md file opens with a rendered preview beside the editor that updates while you type (Ctrl + Shift + V, or the Preview button). .txt, .inp, .out and .ans open as plain text; live checking, IntelliSense, Format and Build skip them.

Tabs

Each tab keeps its own undo history, test cases and input. Drag to reorder and middle-click to close. Right-click a tab for Close, Close Others, Rename, Copy Path and Checkpoints; right-click the + to create a C++, C, input, output, text or Markdown file. Open tabs are restored when you reopen the IDE.

You can also drop files onto the window, or open them from Windows Explorer with "Open with Sameko Dev C++"; they open in the running window.

Inspect, pause, understand

Integrated GDB debugger

Set a breakpoint in the gutter and press F5: Sameko builds with debug information and opens the Debug panel beside the editor. It drives the bundled MinGW GDB on Windows; Linux uses the system gdb.

Control the session

Continue, Pause, Step Over / Into / Out, Run to Cursor, Restart and Stop in one row.

Read the current state

Locals, watches, STL values, the call stack and hover-to-evaluate.

Auto dry run

Walks from main() with a speed slider. Esc stops it.

Replay a pause

Back replays recorded pauses read-only; Back to live continues.

Shortcut note

F5 starts or continues debugging, F10 steps over, F11 steps into, Shift + F11 steps out and Shift + F5 stops. When you are not debugging, F10 runs and F11 builds and runs. Breakpoints move with the code when you add or remove lines above them.

File Explorer

Open a folder (Ctrl + E shows or hides the Explorer) to browse and manage files without leaving the IDE.

  • Files lists the folder's files and subfolders; the open file is highlighted and follows the active tab
  • The filter box at the top finds any file in the folder; Enter opens the first match, Esc clears it
  • Recent keeps the last three files you opened
  • Contest and Collections group problems, with a status (such as Done) and notes for each file
  • Right-click for New File, Rename, Delete and other file operations; New File uses your template from Settings › Template
  • Build output (.exe, .o, ...) is hidden behind a "build files hidden · Show" link

Checkpoints (Local History)

Sameko saves a checkpoint every time you save a changed file, so you can go back to an earlier version even after closing the IDE.

How It Works

  1. Every Ctrl + S that changes the file creates a timestamped checkpoint
  2. Right-click the tab › Checkpoints to see all saved versions
  3. Click a checkpoint to preview it
  4. Restore it to revert the file; Ctrl + Z brings back the text from before the restore
Tip

Checkpoints are stored locally and survive restarts and renames. Set how long they are kept with "Delete After (days)" in Settings. Great for trying different solutions during a contest.

Competitive Companion and tests

Competitive Companion is a browser extension that sends a problem and its sample tests from online judges such as Codeforces and AtCoder to the IDE.

Setup

  1. Install Competitive Companion on Chrome or Firefox
  2. Open Sameko IDE
  3. Navigate to a problem page and click the extension icon
  4. The problem file and its test cases appear in the IDE

Input, Output and Expected

Each tab has an Input, Output and Expected card. When Expected is filled, Output shows AC or WA · N lines after a run. The file button on the Input card (or dropping a file on it) feeds a .txt file to the program instead of the typed input, which suits very large tests.

Run All Tests and verdicts

Run All Tests runs a tab's test cases on up to four workers; a test close to the time limit is run again on its own. Each case shows a verdict:

  • AC - Accepted, output matches expected
  • WA - Wrong Answer, output differs
  • TLE - Time Limit Exceeded
  • MLE - Memory Limit Exceeded
  • RE - Runtime Error
  • CE - Compilation Error

Snippets

Snippets insert code templates when you type a short prefix and pick it from the suggestion list with Tab or Enter.

Built-in Snippets

Prefix Template
cp Competitive programming template with bits/stdc++.h and fast I/O
for / for1 / ford Loop 0 → n-1 / 1 → n / n-1 → 0
vec / vecn / vecval Vector / with size n / with size n and a value
vv 2D vector
all / rall v.begin(), v.end() / reverse range
ios Fast I/O
fre File I/O with freopen
setp Set output precision

STL IntelliSense

Clangd provides context-aware completion, documentation hover and signature help for STL members such as push_back, sort, lower_bound and substr. Built-in snippets, keywords and common standard-library names stay available while clangd warms up.

Custom Snippets

Go to Settings › Snippets to create your own: each has a prefix (trigger word) and a body (the inserted code). Import from File(s) adds one snippet per file, named after the file. Use it for your own BFS, DFS, Segment Tree or DSU templates.

Auto-Update

The installed version of Sameko checks GitHub Releases for updates in the background.

How It Works

  1. After startup, the IDE looks for a newer stable release
  2. If one is found, it downloads in the background
  3. A notification appears when the download is complete
  4. Click Restart to update: the new version installs silently and reopens with your files
Beta updates

Only stable releases are offered by default. Turn on Settings › About › Get beta updates to also receive pre-releases.

Note

Auto-update is only available in the installed version. Portable users download new versions manually.

Troubleshooting

IDE won't open

Right-click Sameko Dev C++.exe, select Properties, check "Unblock" at the bottom, then Apply.

Windows Defender blocks the download

A common false positive for new Electron apps. Choose More info → Run anyway, or unblock the .exe as above.

"Missing DLL" error

Install Visual C++ Redistributable from this link.

Compile doesn't work

Check the following:

  • Antivirus isn't blocking gcc.exe or the program you built
  • The file is saved with a .cpp or .c extension (text and Markdown files are not built)
  • On Linux, g++ is installed and on your PATH

Terminal not showing output

Press Ctrl + J to open the bottom panel. If it is still empty, restart the IDE.
