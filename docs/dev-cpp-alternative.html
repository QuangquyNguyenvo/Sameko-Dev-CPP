Background

Two different programs.

Then

Dev-C++ is the classic Windows IDE that many schools still teach with. It was created by Bloodshed and later continued by Orwell and then Embarcadero. It ships with TDM-GCC 9.2.

vs
Now

Sameko Dev C++ is a separate, newer IDE with a similar name and the same goal: a C++ editor that works the moment it is installed. It is an independent open-source project, not a fork of Dev-C++, built on the Monaco editor (the editor inside VS Code).

Same

What stays the same.

  • No setup. The compiler is in the download. Install, open a file, run.

  • F9F10F11

    The same keys. F9 compiles, F10 runs, F11 compiles and runs.

  • Single files first. One .cpp file is a program. No project to create.

  • Portable. A zip that runs from a USB drive without admin rights.

  • Free. Open source, no account, no ads.

New

What is different.

C++26

A current compiler

Sameko Dev C++ bundles GCC 16 on Windows and supports C++98 through C++26. Dev-C++ ships with TDM-GCC 9.2, which was released before C++20 and C++23 were finished, so most features of those standards are missing there unless you replace the compiler yourself.

Errors while you type

clangd checks the code as you write and underlines mistakes before you compile. Completion understands templates, the STL and your own types.

AC

Made for online judges

Test cases live next to the code, with Output and Expected side by side. Run every test at once and see the verdict, time and memory for each. Competitive Companion imports problems and tests from online judges.

A debugger in the editor

GDB with breakpoints in the margin, watches and the call stack.

Windows and Linux

Dev-C++ runs on Windows. Sameko Dev C++ also has a Linux AppImage, which uses the compiler installed on the system.

The rest

Local history with checkpoints, snippets, code formatting on save, a Markdown preview, a dark mode and a theme editor, and an interface in English, Tiếng Việt and 简体中文.

Switch

Moving from Dev-C++.

  1. 1

    Download Sameko Dev C++: the installer, or the portable zip if you cannot install software on the machine.

  2. 2

    Open one of your existing .cpp files. Nothing needs converting.

  3. 3

    Press F11. The first build uses the bundled GCC 16.

  4. 4

    If your course or judge expects an older standard, pick it in Settings → Compiler.

You can keep both IDEs installed side by side. They do not share settings or a compiler.
