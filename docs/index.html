Getting started

Up and running in two minutes

No MinGW install. No PATH surgery. No tasks.json.

  1. 1

    Download

    Grab the installer or the portable zip. The GCC 16 toolchain ships inside — nothing else to install.

  2. 2

    Open a .cpp

    Drop in a file or start a new one. clangd indexes it immediately; no project file to configure.

  3. 3

    Press F11

    Compile and run. Output streams line by line while the program is still running.

Features

Everything a competitive setup needs

Built around the loop you actually run a hundred times a day: write, build, run, inspect, fix.

500 ms builds

GCC 16 paired with the LLD linker and a warm cache. Compile-and-run is fast enough that you stop thinking about it.

Real clangd IntelliSense

Actual language-server completion, diagnostics and go-to-definition — not a hardcoded list of STL names.

A debugger you'll use

Gutter breakpoints, watches, STL-aware variable trees, call stack, hover-to-evaluate and Run to Cursor — on the bundled GDB.

Auto dry run

Walks your program a line at a time while the values update, so you can watch a loop run instead of pressing F10 a hundred times. Starts at main().

Step back

Every pause is recorded, so Back lets you revisit earlier steps and the values they held.

Competitive Companion

Pull problems and test cases straight from Codeforces, AtCoder, CSES and friends, then run them all in one click.

Snippets

Built-in templates for BFS, DFS, segment trees and the rest — plus your own, expanded by prefix.

Checkpoints

Local history that saves as you work. Browse previous versions and restore any of them without touching git.

Six themes, plus yours

Kawaii Dark/Light, Sakura, Dracula, Monokai and Nord — or build your own in the theme customizer.
