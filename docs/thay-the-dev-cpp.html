Thay thế Dev-C++

Quen Dev‑C++? Thử bản đời mới.

Sameko Dev C++ giữ đúng cái làm Dev-C++ dễ dùng: mở file .cpp, nhấn F11, thấy chương trình chạy. Còn compiler, trình soạn thảo và debugger thì mới hết.

Tải Sameko Dev C++ Xem bảng so sánh

Hai phần mềm khác nhau.

Dev-C++ là IDE quen thuộc trên Windows mà nhiều trường vẫn đang dạy. Bloodshed làm ra nó, sau đó Orwell rồi Embarcadero phát triển tiếp. Bản hiện tại đi kèm TDM-GCC 9.2.

Sameko Dev C++ là một IDE khác, mới hơn, tên gần giống và cùng mục tiêu: cài xong là code được ngay. Đây là dự án mã nguồn mở độc lập, không phải bản fork của Dev-C++, xây trên Monaco (trình soạn thảo bên trong VS Code).

Những thứ vẫn y như cũ.

  • Không phải thiết lập gì. Compiler nằm sẵn trong bản tải về. Cài, mở file, chạy.
  • Phím tắt quen tay. F9 compile, F10 chạy, F11 compile rồi chạy luôn.
  • Một file là đủ. Một file .cpp là một chương trình, không cần tạo project.
  • Portable. Bản zip chạy thẳng từ USB, không cần quyền admin. Hợp với máy phòng thi, phòng máy ở trường.
  • Miễn phí. Mã nguồn mở, không tài khoản, không quảng cáo.

Những thứ khác đi.

Compiler mới

Sameko Dev C++ đi kèm GCC 16 trên Windows, dùng được từ C++98 đến C++26. Dev-C++ đi kèm TDM-GCC 9.2, ra đời trước khi C++20 và C++23 hoàn thiện, nên phần lớn tính năng của hai chuẩn này không dùng được nếu bạn không tự thay compiler.

Báo lỗi ngay lúc gõ

clangd kiểm tra code trong lúc bạn viết và gạch chân chỗ sai trước khi compile. Gợi ý code hiểu được template, STL và các kiểu bạn tự định nghĩa.

Làm ra cho online judge

Test case nằm ngay cạnh code, Output và Expected đặt cạnh nhau. Chạy hết các test một lượt là thấy verdict, thời gian và bộ nhớ của từng test. Competitive Companion lấy đề và test từ các online judge về giúp bạn.

Debugger ngay trong trình soạn thảo

GDB với breakpoint đặt ở lề, watch và call stack.

Windows và Linux

Dev-C++ chạy trên Windows. Sameko Dev C++ có thêm bản AppImage cho Linux, dùng compiler cài sẵn trên máy.

Mấy thứ còn lại

Lịch sử file với checkpoint, snippet, tự định dạng code khi lưu, xem trước Markdown, giao diện tối và trình chỉnh theme, cùng giao diện Tiếng Việt, English và 简体中文.

Chuyển từ Dev-C++ sang.

  1. Tải Sameko Dev C++: bản cài, hoặc bản zip portable nếu máy không cho cài phần mềm.
  2. Mở một file .cpp bạn đang có. Không phải chuyển đổi gì.
  3. Nhấn F11. Lần build đầu dùng luôn GCC 16 có sẵn.
  4. Nếu lớp học hay judge yêu cầu chuẩn cũ hơn, chọn lại trong Cài đặt → Compiler.

Hai IDE cài song song được, không đụng cài đặt hay compiler của nhau.

Hỏi đáp.

Sameko Dev C++ có phải bản mới của Dev-C++ không?

Không. Dev-C++ là một IDE khác, do Bloodshed làm ra, sau đó Orwell rồi Embarcadero phát triển tiếp. Sameko Dev C++ là dự án độc lập, viết mới từ đầu trên Electron và trình soạn thảo Monaco. Nó không phải bản fork và không dùng chung dòng code nào với Dev-C++.

Phím tắt quen của Dev-C++ còn dùng được không?

Mấy phím chính thì y nguyên: F9 để compile, F10 để chạy, F11 để compile rồi chạy luôn. Shift+F5 để dừng chương trình. Muốn đổi phím nào thì vào Cài đặt.

Mở lại file cũ từ Dev-C++ được không?

Được. File .cpp và .h chỉ là file chữ, mở ra là dùng, không phải chuyển đổi gì.

Có phải cài compiler riêng không?

Trên Windows thì không. GCC 16, clangd và GDB nằm sẵn trong bản tải về, giống như Dev-C++ đi kèm TDM-GCC. Trên Linux thì app dùng g++, gdb và clangd cài từ distro của bạn.

Có miễn phí như Dev-C++ không?

Có. Sameko Dev C++ là mã nguồn mở, giấy phép MIT, không quảng cáo, không cần tài khoản, không thu thập dữ liệu.

Dev-C++ là sản phẩm của các tác giả tương ứng. Sameko Dev C++ không liên quan đến Bloodshed, Orwell hay Embarcadero. Bảng so sánh mô tả bản cài mặc định, kiểm tra lần cuối vào tháng 11/2026.
