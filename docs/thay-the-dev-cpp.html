Thay thế Dev-C++

Quen Dev‑C++? Thử bản đời mới.

Bạn vẫn mở file .cpp, nhấn F11 là chương trình chạy, y như hồi dùng Dev-C++. Chỉ khác là compiler, trình soạn thảo và debugger đều mới hơn nhiều.

Hai phần mềm khác nhau.

Trước

Dev-C++ là IDE mà chắc bạn đã gặp ở trường. Bloodshed làm ra nó, sau đó Orwell rồi Embarcadero phát triển tiếp. Bản hiện tại đi kèm TDM-GCC 9.2.

vs
Giờ

Sameko Dev C++ là một IDE khác, mới hơn. Tên nghe gần giống và mục tiêu cũng vậy, đó là cài xong bạn code được ngay. Đây là dự án mã nguồn mở độc lập, không phải bản fork của Dev-C++, và được xây trên Monaco, trình soạn thảo nằm bên trong VS Code.

Giữ nguyên

Những thứ bạn vẫn quen.

  • Không phải thiết lập gì. Compiler có sẵn trong bản tải về. Bạn cài, mở file rồi chạy thôi.

  • F9F10F11

    Phím tắt quen tay. Bạn vẫn nhấn F9 để compile, F10 để chạy, F11 để compile rồi chạy luôn.

  • Một file là đủ. Mỗi file .cpp là một chương trình, bạn không cần tạo project.

  • Mang theo được. Bản zip chạy thẳng từ USB, không cần quyền admin, rất hợp với máy phòng thi hay phòng máy ở trường.

  • Miễn phí. Mã nguồn mở, không cần tài khoản, không quảng cáo.

Mới

Những thứ bạn được thêm.

C++26

Compiler mới

Bạn có GCC 16 trên Windows, dùng được từ C++98 đến C++26. Dev-C++ đi kèm TDM-GCC 9.2, ra đời trước khi C++20 và C++23 hoàn thiện. Vì vậy phần lớn tính năng của hai chuẩn này bạn sẽ không dùng được, trừ khi tự thay compiler.

Báo lỗi ngay lúc gõ

clangd kiểm tra code ngay lúc bạn viết và gạch chân chỗ sai trước khi bạn compile. Gợi ý code cũng hiểu template, STL và các kiểu bạn tự định nghĩa.

AC

Làm ra cho online judge

Test case nằm ngay cạnh code, Output và Expected đặt sát nhau cho bạn dễ so. Bạn chạy hết các test một lượt là thấy verdict, thời gian và bộ nhớ của từng test. Competitive Companion còn lấy đề và test từ các online judge về giúp bạn.

Debugger ngay trong trình soạn thảo

Bạn đặt breakpoint ngay ở lề, theo dõi biến bằng watch và xem call stack, tất cả chạy bằng GDB.

Windows và Linux

Dev-C++ chỉ chạy trên Windows. Sameko Dev C++ có thêm bản AppImage cho Linux, dùng compiler cài sẵn trên máy bạn.

Mấy thứ còn lại

Bạn còn có lịch sử file với checkpoint, snippet, tự định dạng code khi lưu, xem trước Markdown, giao diện tối và trình chỉnh theme. Giao diện có Tiếng Việt, English và 简体中文.

Chuyển sang

Chuyển từ Dev-C++ sang.

  1. 1

    Tải Sameko Dev C++ về. Bạn chọn bản cài, hoặc bản zip portable nếu máy không cho cài phần mềm.

  2. 2

    Mở một file .cpp bạn đang có. Bạn không phải chuyển đổi gì cả.

  3. 3

    Nhấn F11. Lần build đầu dùng luôn GCC 16 có sẵn.

  4. 4

    Nếu lớp học hay judge của bạn yêu cầu chuẩn cũ hơn, bạn chọn lại trong Cài đặt → Compiler.

Bạn cứ để hai IDE cài song song, chúng không đụng cài đặt hay compiler của nhau.
