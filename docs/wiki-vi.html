Release notes · 1.3.2 · 20/10/2026

Có gì mới trong Sameko 1.3.2

Xem trước Markdown, định dạng khi lưu, bớt thao tác thừa.

Xem trước Markdown

File .md mở kèm bản hiển thị cập nhật ngay khi gõ. Bật/tắt bằng Ctrl + Shift + V.

Định dạng khi lưu

Chọn 1 trong 13 kiểu AStyle ở Settings › Editor; một lần Ctrl + Z là hoàn tác phần định dạng.

Tạo file đủ loại

Chuột phải nút + cạnh thanh tab để tạo file C++, C, .inp, .out, text hoặc Markdown.

Đổi tên tab

Chuột phải tab › Rename. File trên đĩa, breakpoint và lịch sử đi theo.

Tìm trong Settings

Gõ vào ô trên cùng của Settings để lọc cài đặt và phím tắt ở mọi tab.

Nhập và kéo thả file

Nhập template hoặc snippet từ file, kéo thả file vào cửa sổ để mở.

Từ bản 1.3.0 đến nay

1.3.1 làm lại Theme Customizer, cho mở file trực tiếp từ Windows Explorer ("Open with"), và đọc .txt, .inp, .out, .ans dạng văn bản thường. 1.3.0 mang lại kiểm tra lỗi trực tiếp bằng clangd (khoảng 100–130 ms), chạy test song song, đo đúng thời gian chạy và bộ nhớ tối đa, đọc input từ file và Electron 44.

Phạm vi phiên bản

Windows có sẵn GCC 16.1.0, clangd, GDB và AStyle; Linux dùng công cụ đã cài trên máy.

Sameko Dev C++ Wiki

Tài liệu từ cơ bản đến nâng cao.

Sameko Dev C++ là IDE C++ miễn phí, mã nguồn mở (MIT), dành cho lập trình thi đấu và học tập, xây dựng trên Monaco Editor. Trên Windows, Sameko có sẵn GCC 16.1.0, clangd và GDB nên bạn có thể viết, chạy và debug C++ ngay sau khi cài, không cần tự cài MinGW. Tài liệu này viết cho bản 1.3.2.

Sameko dành cho ai?

  • Người mới học cần môi trường đơn giản, không phức tạp như Visual Studio
  • Người lập trình thi đấu cần build nhanh, test case và Competitive Companion
  • Học sinh, sinh viên cần IDE portable để dùng trên máy trường qua USB

Cài đặt Sameko IDE

Nên chọn bản nào?

Windows có 2 bản tải:

  • Installer (sameko-dev-cpp-setup-<version>.exe) - có shortcut ở Start Menu và Desktop, mở file C++ bằng "Open with", tự cập nhật và có trình gỡ cài đặt. Khuyên dùng cho đa số người dùng.
  • Portable (.zip) - giải nén là chạy, không cần quyền admin, không ghi registry. Hợp để chạy từ USB hoặc máy ở trường. Bản portable không tự cập nhật.

Tải Sameko

Vào trang chủ và bấm Download, hoặc tải từ GitHub Releases.

Cài đặt hoặc giải nén

Installer: chạy file .exe và làm theo hướng dẫn. Chỉ hỏi quyền admin nếu bạn cài vào Program Files.
Portable: giải nén vào thư mục như D:\Sameko-IDE\.

Mở Sameko Dev C++

Mở từ Start Menu, hoặc nhấp đúp Sameko Dev C++.exe trong thư mục portable.

Cảnh báo của Windows Defender

App mới có thể bị báo "not commonly downloaded" hoặc SmartScreen. Chọn Keep, hoặc More info → Run anyway.

Bản Linux

Bản Linux có dạng AppImage, .deb và .tar.gz, không kèm compiler. Hãy cài g++, gdb, clangd và astyle từ bản phân phối của bạn để Sameko nhận ra.

Tạo project đầu tiên

Sau khi mở IDE, hãy viết và chạy chương trình Hello World để kiểm tra mọi thứ hoạt động.

#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << "Hello, Sameko!" << '\n';
    return 0;
}

Các bước:

  1. Nhấn Ctrl + N để tạo file mới (bắt đầu từ template trong Settings › Template) rồi dán code vào
  2. Nhấn Ctrl + S để lưu thành hello.cpp
  3. Nhấn F11 để build và chạy
  4. Kết quả hiện ở Terminal và thẻ Output; thanh trạng thái hiện thời gian chạy và bộ nhớ tối đa
Mẹo

F9 chỉ biên dịch, F10 chạy không build lại, F11 làm cả hai. Các lựa chọn này cũng có trong mũi tên cạnh nút Run.

Cài đặt trình biên dịch

Sameko dùng GCC 16.1.0 trên Windows. Đổi chuẩn C++, mức tối ưu và flag thêm trong Settings › Compiler.

Chuẩn C++

Chọn bất kỳ chuẩn nào từ C++98 đến C++26. Default là C++17, chuẩn mà phần lớn online judge và người thi đấu dùng.

Chuẩn Mô tả
C++98 Cũ, hiện ít dùng
C++11 / C++14 Ổn định, phổ biến, có auto, lambda
C++17 (Mặc định) Lựa chọn phổ biến nhất cho lập trình thi đấu
C++20 Thêm Ranges, Concepts, Modules
C++23 Thêm std::print, std::expected
C++26 Có trong GCC 16.1.0; dùng khi compiler bạn nộp bài hỗ trợ tính năng đó

Các flag thường dùng

  • -O2 - tối ưu tốc độ, giống phần lớn online judge
  • -Wall - hiện cảnh báo, giúp tìm lỗi
  • -g - thêm thông tin debug (F5 tự thêm cho bạn)
Build lại nhanh

Sameko dùng bits/stdc++.h biên dịch sẵn, và build lại file không đổi thì dùng luôn file chạy lần trước.

Theme Customizer

Bản xem trước là bản thu nhỏ của chính cửa sổ app: bấm vào phần nào thì nhảy tới màu của phần đó. Màu nhập được dạng HEX, RGB hoặc RGBA, mỗi màu đã đổi có nút hoàn tác riêng, và Ctrl + Z / Ctrl + Y để hoàn tác/làm lại. Thay đổi chỉ nằm trong bản xem trước cho tới khi bạn lưu.

Bạn có thể thêm ảnh hoặc video nền với thanh chỉnh độ mờ, sửa theme dạng JSON và xuất theme. Theme xuất ra mang theo cả file nền.

Cỡ giao diện và video nền

Settings › Appearance có Interface Scale (80–200%, Auto tự phóng to trên màn 4K) và công tắc Animated Background để tắt video nền. Video tự dừng khi bạn làm việc ở cửa sổ khác.

Editor

Sameko dùng Monaco Editor, cùng nhân với VS Code, và clangd cho các tính năng ngôn ngữ C++.

Tính năng chính

  • IntelliSense - gợi ý, hover và chữ ký hàm từ clangd cho STL và code của bạn
  • Kiểm tra lỗi trực tiếp - báo lỗi và cảnh báo ngay khi gõ, từ clangd (khoảng 100–130 ms)
  • Định dạng code - Ctrl + Shift + A, có 13 kiểu AStyle trong Settings › Editor › Format Style, và Format on Save cho file C/C++
  • Tự đóng kiểu - gõ { sau struct Name (hoặc class, union, enum) sẽ thành {};
  • Nhiều con trỏ - giữ Alt rồi click, hoặc Ctrl + D để chọn chỗ trùng tiếp theo
  • Tìm & thay thế - Ctrl + H, hỗ trợ regex
  • Chia đôi editor - Ctrl + \ để làm hai file cạnh nhau
  • Tô màu ngoặc, minimap và thu gọn code

Markdown và file test

File .md mở kèm bản xem trước cập nhật ngay khi gõ (Ctrl + Shift + V, hoặc nút Preview). .txt, .inp, .out và .ans mở dạng văn bản thường; kiểm tra lỗi, IntelliSense, Format và Build bỏ qua các file này.

Tab

Mỗi tab giữ lịch sử undo, test case và input riêng. Kéo để đổi thứ tự, click chuột giữa để đóng. Chuột phải tab để có Close, Close Others, Rename, Copy Path và Checkpoints; chuột phải nút + để tạo file C++, C, input, output, text hoặc Markdown. Các tab đang mở được khôi phục khi mở lại IDE.

Bạn cũng có thể kéo thả file vào cửa sổ, hoặc mở từ Windows Explorer bằng "Open with Sameko Dev C++"; file sẽ mở trong cửa sổ đang chạy.

Dừng, xem, hiểu

Debugger GDB tích hợp

Đặt breakpoint ở lề trái rồi nhấn F5: Sameko build kèm thông tin debug và mở bảng Debug cạnh editor. Trên Windows dùng MinGW GDB đi kèm; Linux dùng gdb của hệ thống.

Điều khiển phiên debug

Continue, Pause, Step Over / Into / Out, Run to Cursor, Restart và Stop trên một hàng.

Xem trạng thái

Biến cục bộ, watch, giá trị STL, call stack và rê chuột để xem giá trị.

Tự chạy từng bước

Đi từ main() với thanh chỉnh tốc độ. Esc để dừng.

Xem lại các lần dừng

Back phát lại các lần dừng đã ghi (chỉ xem); Back to live để chạy tiếp.

Lưu ý phím tắt

F5 bắt đầu hoặc tiếp tục debug, F10 step over, F11 step into, Shift + F11 step out và Shift + F5 dừng. Khi không debug, F10 là chạy và F11 là build và chạy. Breakpoint đi theo code khi bạn thêm/xóa dòng phía trên.

File Explorer

Mở một thư mục (Ctrl + E để hiện/ẩn Explorer) để duyệt và quản lý file ngay trong IDE.

  • Files liệt kê file và thư mục con; file đang mở được tô sáng và đi theo tab hiện tại
  • Ô lọc phía trên tìm file bất kỳ trong thư mục; Enter mở kết quả đầu, Esc xóa ô lọc
  • Recent giữ 3 file mở gần nhất
  • Contest và Collections gom bài theo nhóm, mỗi file có trạng thái (như Done) và ghi chú
  • Chuột phải để New File, Rename, Delete và các thao tác khác; New File dùng template trong Settings › Template
  • File build ra (.exe, .o, ...) được ẩn sau link "build files hidden · Show"

Checkpoints (Lịch sử cục bộ)

Mỗi lần bạn lưu file có thay đổi, Sameko tạo một checkpoint, nên luôn quay lại được bản cũ, kể cả sau khi đóng IDE.

Cách hoạt động

  1. Mỗi lần Ctrl + S làm file thay đổi sẽ tạo một checkpoint kèm thời gian
  2. Chuột phải tab › Checkpoints để xem các bản đã lưu
  3. Bấm vào checkpoint để xem trước
  4. Khôi phục để đưa file về bản đó; Ctrl + Z lấy lại nội dung trước khi khôi phục
Mẹo

Checkpoint lưu trên máy, giữ nguyên sau khi khởi động lại hay đổi tên file. Chỉnh thời gian giữ bằng "Delete After (days)" trong Settings. Rất tiện để thử nhiều cách giải trong lúc thi.

Competitive Companion và test

Competitive Companion là extension trình duyệt, gửi đề bài và test mẫu từ các online judge như Codeforces, AtCoder vào IDE.

Thiết lập

  1. Cài Competitive Companion trên Chrome hoặc Firefox
  2. Mở Sameko IDE
  3. Vào trang đề bài và bấm icon extension
  4. File bài và test case xuất hiện trong IDE

Input, Output và Expected

Mỗi tab có thẻ Input, Output và Expected. Khi đã điền Expected, sau mỗi lần chạy thẻ Output hiện AC hoặc WA · N lines. Nút file trên thẻ Input (hoặc kéo thả file vào) cho chương trình đọc input từ file .txt thay vì ô nhập, hợp với test rất lớn.

Run All Tests và kết quả

Run All Tests chạy các test của tab trên tối đa 4 luồng; test sát giới hạn thời gian được chạy lại riêng. Mỗi test hiện một kết quả:

  • AC - Accepted, output khớp expected
  • WA - Wrong Answer, output khác
  • TLE - Quá thời gian
  • MLE - Quá bộ nhớ
  • RE - Lỗi khi chạy
  • CE - Lỗi biên dịch

Snippets

Snippet chèn mẫu code khi bạn gõ một tiền tố ngắn rồi chọn trong danh sách gợi ý bằng Tab hoặc Enter.

Snippet có sẵn

Tiền tố Mẫu code
cp Template lập trình thi đấu với bits/stdc++.h và fast I/O
for / for1 / ford Vòng lặp 0 → n-1 / 1 → n / n-1 → 0
vec / vecn / vecval Vector / kích thước n / kích thước n kèm giá trị
vv Vector 2 chiều
all / rall v.begin(), v.end() / khoảng đảo ngược
ios Fast I/O
fre Đọc/ghi file bằng freopen
setp Đặt số chữ số thập phân khi in

STL IntelliSense

Clangd gợi ý theo ngữ cảnh, hiện tài liệu khi rê chuột và chữ ký hàm cho các thành viên STL như push_back, sort, lower_bound, substr. Snippet có sẵn, từ khóa và tên thư viện chuẩn thông dụng vẫn được gợi ý trong lúc clangd khởi động.

Snippet tự tạo

Vào Settings › Snippets để tạo snippet riêng: mỗi snippet có tiền tố (từ kích hoạt) và nội dung (code được chèn). Import from File(s) thêm mỗi file thành một snippet, đặt tên theo file. Dùng để lưu template BFS, DFS, Segment Tree hay DSU của bạn.

Xử lý sự cố

IDE không mở được

Chuột phải Sameko Dev C++.exe, chọn Properties, tick "Unblock" ở dưới cùng, rồi Apply.

Windows Defender chặn file tải về

Đây là báo nhầm thường gặp với app Electron mới. Chọn More info → Run anyway, hoặc Unblock file .exe như trên.

Lỗi "Missing DLL"

Cài Visual C++ Redistributable từ link này.

Không biên dịch được

Kiểm tra:

  • Antivirus không chặn gcc.exe hoặc chương trình vừa build
  • File được lưu với đuôi .cpp hoặc .c (file text và Markdown không được build)
  • Trên Linux, đã cài g++ và nó nằm trong PATH

Terminal không hiện output

Nhấn Ctrl + J để mở bảng dưới. Nếu vẫn trống, khởi động lại IDE.
