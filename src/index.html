Snippet Tips (Smart Template)
• ${1:ten_bien} : Tab stop #1, press Tab to jump here. Has default content.
• ${2} : Tab stop #2, press Tab again to go here.
• ${0} : Final tab stop (usually placed inside brackets { }).
Examples:
1. Loop: 
for(int i=0; i<${1:n}; i++) {\n    ${0}\n}
2. Output / Vector: 
cout<<${1:res}<<"\\n";\nvector<${1:int}> ${2:v};
3. Quick function: 
${1:void} ${2:solve}() {\n    ${0}\n}
